Deliberate delegation

Less overhead. More signal.

Keep the expensive model in the loop where it matters: planning the task and reviewing the result. Let a fit-for-purpose worker do the execution.

01 / PLAN

Lead with judgment

Your frontier model defines the task, constraints and review bar. It remains accountable for the outcome.

02 / DISPATCH

Pick a worker

Send each task to the provider and model that makes sense for its difficulty, risk and budget.

03 / REVIEW

Keep the evidence

SwitchRelay records the session, cost, status and parent relationship so every result stays reviewable.

One honest ledger

See what happened, not just what shipped.

A local state file retains a clear account of who did the work, what model ran, what it cost, and whether someone has reviewed it.

  • →Session ID and cost captured automatically
  • →Parent model and parent run linked to every child
  • →Atomic writes and exclusive locks for reliable local state

Quickstart

From zero to a tracked worker in two commands.

Bring Node.js 22+ and an authenticated OpenCode provider. Everything else stays on your machine.

Your repository stays yours.SwitchRelay is not a CI system and never merges, pushes, or deploys for you.
terminal
# Install the local control plane
npm install --global switch-relay
switchrelay check

# Dispatch one focused task
switchrelay run --repo /path/to/repository --title "Handle API fetch errors" --role builder --model openrouter/deepseek/deepseek-v4 --parent openai/codex --prompt "Add focused error handling."
